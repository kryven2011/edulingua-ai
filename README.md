# 🎓 EduLingua AI — Production-Ready Telegram Educational AI Platform

**EduLingua AI** — высоконагруженная образовательная платформа в Telegram, объединяющая интеллектуального ИИ-репетитора по академическим предметам (**EduAI**) и адаптивного преподавателя иностранных языков (**LinguaBot**).

---

## ⚡ 1. Архитектурный принцип — WEBHOOK ONLY

> **СТРОГОЕ ТРЕБОВАНИЕ:** Платформа работает **исключительно через HTTPS Webhook**.
> В проекте **полностью отсутствует Long Polling / getUpdates**.

### Схема обработки событий:
```
Telegram Servers
       │  (HTTPS POST /telegram/webhook)
       ▼
 [Caddy / Reverse Proxy with SSL]
       │
       ▼
 [FastAPI Webhook Server]
       ├── 1. Проверка X-Telegram-Bot-Api-Secret-Token (hmac.compare_digest)
       ├── 2. Парсинг и валидация JSON payload
       ├── 3. Защита от дублей update_id через Redis SETNX (TTL 24ч)
       ├── 4. Постановка в очередь Redis (RPUSH telegram:updates:queue)
       └── 5. Быстрый возврат HTTP 200 "ok" (время ответа < 15мс)
       
 [Redis Queue (telegram:updates:queue)]
       │
       ▼
 [Async Telegram Worker (BLPOP)]
       ├── 1. Десериализация Update
       ├── 2. Передача в aiogram 3.x Dispatcher
       ├── 3. Выполнение FSM, Router и Middlewares (DB, User, RateLimit, Throttle)
       ├── 4. Повторные попытки при сбоях (до 3 раз с задержкой)
       └── 5. Перемещение невосстановимых ошибок в Dead-Letter Queue (DLQ)
```

## 🌟 2. Основные возможности платформы

### 👤 Многошаговая регистрация (Onboarding Flow)
При нажатии `/start` бот проверяет регистрацию в PostgreSQL:
1. **Шаг 1: Приветствие и выбор языка интерфейса** (Русский 🇷🇺, Oʻzbekcha 🇺🇿, English 🇬🇧).
2. **Шаг 2: Имя пользователя** (подтверждение имени из Telegram или ручной ввод).
3. **Шаг 3: Цель обучения** (EduAI — школьные предметы, LinguaBot — иностранные языки, или Всё вместе).
4. **Шаг 4: Выбор иностранного языка** (English, Russian, Uzbek, German, French, Spanish).
5. **Шаг 5: Оценка уровня** (A1, A2, B1, B2, C1).
6. **Шаг 6: Финализация** — сохранение в PostgreSQL, начисление стартового бонуса **+50 XP** (с защитой от повторного начисления) и отображение Главного меню.

### 🌍 Модуль LinguaBot (Изучение языков)
- **Языки:** Английский, Русский, Узбекский, Немецкий, Французский, Испанский.
- **Словарный запас (Vocabulary):** интервальное повторение по алгоритму **SuperMemo-2 (SM-2)** с оценкой качества запоминания (0–5).

- **Письмо (Writing):** проверка эссе и текстов, оценка по шкале CEFR (A1–C2), исправление орфографии и пунктуации.
- **Тест на уровень:** автоматическое определение уровня знаний.

## 🚀 4. Инструкция по развёртыванию

### Шаг 1. Клонирование и настройка окружения
```bash
git clone <repository_url> edulingua-ai
cd edulingua-ai
cp .env.example .env
```

Отредактируйте `.env`:
```ini
TELEGRAM_BOT_TOKEN=123456789:AAFg...ваши_токен_от_BotFather
WEBHOOK_BASE_URL=https://your-domain.com
WEBHOOK_SECRET=сгенерируйте_случайную_строку_секрета
GEMINI_API_KEY=ваш_ключ_от_Google_AI_Studio
DATABASE_URL=postgresql+asyncpg://edulingua:edulingua_password@postgres:5432/edulingua
REDIS_URL=redis://redis:6379/0
ADMIN_SECRET_KEY=секретный_ключ_для_jwt_панели
ADMIN_USERNAME=admin
```

---

### Шаг 2. Запуск через Docker Compose (Рекомендуемый способ)
```bash
# 1. Сборка и запуск контейнеров (Postgres, Redis, API, Worker, Caddy)
docker compose up -d --build

# 2. Инициализация базы данных и сидинг (предметы, языки, квесты, админ)
docker compose exec api python scripts/init_db.py

# 3. Регистрация Webhook в Telegram
docker compose exec api python scripts/manage_webhook.py set

# 4. Проверка состояния webhook
docker compose exec api python scripts/manage_webhook.py check
```

---

### Шаг 3. Локальная разработка (с Cloudflare Tunnel или ngrok)
Так как бот работает **строго через Webhook**, для локального тестирования требуется внешний HTTPS-туннель:

```bash
# Запуск туннеля через Cloudflare
cloudflared tunnel --url http://localhost:8000
```
Скопируйте выданный адрес (например, `https://random-subdomain.trycloudflare.com`) в `WEBHOOK_BASE_URL` в `.env` и выполните:
```bash
python scripts/manage_webhook.py set
```

Запустите сервер и воркер:
```bash
# В терминале 1: Webhook API сервер
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# В терминале 2: Фоновый воркер обработки очереди
python -m app.workers.worker_runner
```

## 🔒 6. Безопасность

1. **Защита Webhook:** заголовок `X-Telegram-Bot-Api-Secret-Token` проверяется через `hmac.compare_digest` в константное время для защиты от timing-атак.
2. **Защита от повторной обработки (Deduplication):** каждый входящий `update_id` атомарно записывается в Redis через `SETNX` с суточным TTL. Повторные запросы игнорируются.
3. **Rate Limiting:** ограничение количества сообщений от одного пользователя в минуту (скользящее окно в Redis).
4. **Anti-flood Throttle:** подавление повторных кликов по inline-кнопкам (интервал 500мс).
5. **Маскирование секретов:** токены и ключи API скрыты через Pydantic `SecretStr` и никогда не попадают в логи.
6. **Админ-панель:** защищена паролями с солью (bcrypt) и сессиями JWT с ограниченным сроком действия.
